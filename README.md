# GaMon (Garbage Monitoring on Web)

Web application for waste collection, sorting, and recycling information (course project).

## Requirements

- PHP 8.1+ (built-in server)

## Run locally

```bash
cd public
php -S localhost:8080
```

Open `http://localhost:8080`.

## Layout

- `public/` — front-end and `api/` entry scripts
- `app/` — back-end PHP includes
- `data/` — local SQLite file (later)
- `docs/` — architecture diagrams

GaMon — Garbage Monitoring on Web

Course: Tehnologii Web 2026  |  Instructor: Assoc. Prof. Dr. Andrei Panu  |  Date: May 2026
Abstract. GaMon is a web application for managing information related to the collection, sorting, and recycling of waste at the level of citizens, authorised personnel, and decision-makers. Users can report garbage accumulation sites; staff can update report statuses and log collection events; decision-makers can view statistical reports and charts. The system exports data in CSV, JSON, HTML, and PDF formats and integrates external geocoding via the Nominatim REST API.

1. Introduction

Waste management is a civic challenge that benefits from digital tooling. GaMon provides a lightweight, browser-based interface backed by a PHP/SQLite server. It targets three user roles: citizen (report waste), staff (manage reports), and decision_maker (analyse data). An admin super-role manages users.

3. Security

  • SQL injection: all database queries use PDO prepared statements.
  • XSS: all DOM output escaped with htmlspecialchars() (PHP) and a custom escHtml() (JS).
  • Authentication: passwords hashed with password_hash() (bcrypt). Session-based auth guard on every protected endpoint.
  • CSRF: a token is generated per session, returned by GET /api/auth/me.php, and validated on every mutating request via the X-CSRF-Token HTTP header.

6. Conclusion

GaMon fulfils all stated functional and non-functional requirements: multi-role authentication, CRUD operations, asynchronous communication, statistical reporting, multi-format export/import, interactive map, external REST integration, and CSRF/SQLi/XSS protection.

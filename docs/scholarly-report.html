GaMon — Garbage Monitoring on Web

Course: Tehnologii Web 2026 Instructor: Assoc. Prof. Dr. Andrei Panu Date: May 2026

Abstract

GaMon is a Web application for managing waste accumulation data at citizen, staff, and decision-maker level. Citizens submit geo-tagged reports of waste accumulation sites. Authorized staff update report statuses and log collection events. Decision-makers view statistical dashboards and export data. The system is built with PHP 8, SQLite, and vanilla JavaScript.

1.2 Non-Functional

  • No server-side or client-side framework (no Laravel, React, jQuery, etc.)
  • SQL injection prevention via PDO prepared statements
  • XSS prevention via htmlspecialchars() on all output
  • Responsive layout (CSS media queries, auto-fit grid)
  • Open-source license (MIT)

2. Architecture

The application follows a simple layered structure:

Browser (HTML + CSS + JS)
    ↕  Fetch / Ajax (JSON)
PHP entry points  public/api/*.php
    ↓  require_once
PHP modules       app/*.php
    ↓  PDO
SQLite            data/gamon.sqlite

The web server document root is public/, so app/ and data/ are not directly accessible from the browser. Each public/api/ file is a thin entry point that delegates to a module in app/.

4. Security

  • SQL injection: All queries use PDO prepared statements with bound parameters.
  • XSS: All data inserted into the DOM is escaped via escHtml() (JS) or htmlspecialchars() (PHP).
  • Authentication: Passwords hashed with password_hash(BCRYPT). Sessions managed server-side.
  • Authorisation: gamon_require_auth($roles) guards every mutating endpoint.
